# Second Brain Starter (Obsidian)

Public starter vault from Reece Hardin's tutorial.

**Easiest path:** click **Use this template** on GitHub → open the folder in Obsidian → turn on Obsidian Git → fill `_identity/` → capture into `00_inbox/`.

Clone URL: `https://github.com/reecehardin/second-brain-demo`

## What you get
- Folder structure ready (people, projects, decisions, companies, meetings, daily, knowledge, maps, inbox)
- `_identity/` starter files: `user.md`, `soul.md`, `identity.md`
- `CLAUDE.md` rules for AI working in the vault
- `nightly-job.md` prompt so the brain compounds overnight
- Git-ready so Mac / Windows / agents stay in sync

## Quick start
1. **Use this template** (or fork/clone) into YOUR GitHub account
2. Open the folder as an Obsidian vault
3. Install **Obsidian Git** → auto commit/push about every 10 minutes
4. Edit `_identity/user.md`, `soul.md`, `identity.md` (or have AI interview you and draft them)
5. Drop captures in `00_inbox/`
6. Schedule `nightly-job.md` with Claude / Cursor / your agent

Do not push to Reece's repo. Make it yours first.
